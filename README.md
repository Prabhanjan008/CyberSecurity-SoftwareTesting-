Cybersecurity & Secure Software Testing

A hands-on repository containing practical implementations of cybersecurity controls and secure coding techniques in Python.

Key Highlights:

Authentication & Authorization: Secure JWT authentication, expiration detection, rate limiting, and password hashing (bcrypt).
Input & Path Validation: Path traversal defenses, strict IP validation, allowed command lists, and file uploads.
System & Data Security: Safe subprocess executions, masked login inputs, secure file handling, and generic error handling.
